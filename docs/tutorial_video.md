# Tutorial Video

We provide a tutorial video that guides users through the installation and use of the SEEG Contact Detector module. The video includes an installation, overview of the module interface, demonstrates the complete workflow for processing a patient data, and explains the available tools for reviewing and adjusting detected contact positions.

The tutorial also presents two representative cases in which the automatic detection did not produce the desired result and demonstrates how these issues can be resolved using the correction tools integrated into the module.
